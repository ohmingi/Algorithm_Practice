## 백준 3190번 뱀 (C++)

이번에 풀어본 문제는 **백준 3190번 뱀**이다.

문제는 아래 링크에서 확인할 수 있다.  
[https://www.acmicpc.net/problem/3190](https://www.acmicpc.net/problem/3190)

### 💻 코드

```
#include <iostream>
#include <queue>
#include <deque>

using namespace std;

int mx = 0;
int my = 1;

int graph[101][101];

void check(int x, int y){
    if(mx == 0){
        if(my == 1){
            mx = 1;
            my = 0;
        }
        else if(my == -1){
            mx = -1;
            my = 0;
        }
    }
    else if(my == 0){
        if(mx == 1){
            mx = 0;
            my = -1;
        }
        else if(mx == -1){
            mx = 0;
            my = 1;
        }
    }
}

void check1(int x, int y){
    if(mx == 0){
        if(my == 1){
            mx = -1;
            my = 0;
        }
        else if(my == -1){
            mx = 1;
            my = 0;
        }
    }
    else if(my == 0){
        if(mx == 1){
            mx = 0;
            my = 1;
        }
        else if(mx == -1){
            mx = 0;
            my = -1;
        }
    }
}

int main() {
    queue<pair<int, char>> q;
    deque<pair<int,int>> dq;

   int n, k;
   cin >> n >> k;

   for(int i = 0; i < k; i++){
    int a, b;
    cin >> a >> b;
    graph[a-1][b-1] = 2;
   }

   int l;
   cin >> l;
   for(int i = 0; i < l; i++){
    int a;
    char b;
    cin >> a;
    cin >> b;
    q.push({a, b});
   }

   int hx = 0;
   int hy = 0;

   dq.push_front({0,0});
   graph[0][0] = 1;

   int cnt = 0;

   while(true){
    cnt++;

    hx += mx;
    hy += my;

    if(hx < 0 || hx >= n || hy < 0 || hy >= n) break;

    if(graph[hx][hy] == 1){
        break;
    }

     if(graph[hx][hy] == 2){
        dq.push_front({hx,hy});
        graph[hx][hy] = 1;
    }
    else{
        dq.push_front({hx,hy});
        graph[hx][hy] = 1;
        pair<int,int> a = dq.back();
        graph[a.first][a.second] = 0;
        dq.pop_back();
    }

    if(!q.empty() && cnt == q.front().first){
        if(q.front().second == 'D'){
            check(mx,my);
        }
        else if(q.front().second == 'L'){
            check1(mx,my);
        }
        q.pop();
    }
   }

   cout << cnt;
}
```

### 🔍 로직 설명

가장 중요한 부분은 크게 3가지로 나뉘는거 같은데 

1\. 뱀이 위치한 좌표들을 어떻게 저장할건가  
2\. 뱀의 90도 회전을 어떻게 처리할건가  
3\. 사과가 있고 없을때를 어떻게 처리할건가 

먼저 2번같은 경우는 그냥 단순하게 큐에 시간과 오른쪽, 왼쪽 명령어를 pair로 저장했고, 시간을 0부터 1씩 증가시켜 시간이 큐의 front와 같을때를 if 처리했다.

그리고 각각 check 함수를 만들어 모든 경우의 수에대해 회전을 어떻게 처리할지 만들었다.  
(같은 오른쪽이더라도 어디를 향해가냐에 따라 x,y방향이 계속 바뀌기에 다 처리를 해주어야 한다.)

문제는 1번이었는데 처음에는 감이 안잡혔다 처음에는 뭐 머리부분과 꼬리 부분만 어떻게 저장해서 처리해야하나? 했는데 몸통이 빠지고, 그러다보니 고뇌에 빠지다가.. 살짝 힌트를 봤는데 deque를 활용해서 모든 부분을 저장하고 빼는 방식을 활용해야했다.   
(지금 생각하면 되게 어렵지 않은 생각인데 왜 생각이 안나는지 잘 모르겠다)

그리고 이중배열로 뱀이 어디 좌표까지 있는지 다 표시를 하고 (이때 1로 표시), 사과는 2로 표시해 3번 문제를 처리했다.

그 다음 종료 조건은 다음으로 갈 좌표가 이중배열에 이미 저장되어있는 값인지 즉 1인지 확인해 맞다면 종료하는식으로 풀면 문제가 풀린다

각각의 삽입과 삭제 등의 연산은 상수지만 최악의 경우 모든 좌표를 확인해야 될 수 도 있기에 o(n^2)이 된다
